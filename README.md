# CRK Logistik Delivery Sistem

Aplikasi sistem manajemen pengiriman untuk admin dan driver.

## Cara Deploy ke GitHub Pages

1. Buat repositori baru di GitHub.
2. Unggah file-file dalam folder ini ke repositori tersebut.
3. Di pengaturan repositori, buka **Pages**, pilih *branch* tempat Anda mengunggah file (misal `main`), dan klik **Save**.
4. Setelah situs aktif, tambahkan URL GitHub Pages Anda ke daftar *Authorized Domains* di **Firebase Console** (Authentication > Settings).
5. Buka aplikasi di GitHub Pages, buka menu **Pengaturan Backend**, dan masukkan URL Web App Google Apps Script Anda.
